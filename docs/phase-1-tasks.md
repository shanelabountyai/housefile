# Phase 1 — Pipeline + matcher + eval (no writes)

Nothing is written to the database in this phase. Input is the two fixture files and `fixtures/crm_constituents.csv`, loaded read-only in memory. Output is a preview report and the `import:eval` table. No Prisma models for constituents or gifts yet, no commit, no review actions, no UI beyond the CLI report. The exit bar is "the TypeScript pipeline agrees with the Python oracle on every row and every pair".

- [ ] **1.1 Scaffold.** Commands in CLAUDE.md exist (`import:eval` prints `0 rows` and exits 0; `fixtures:check`; `model:lint`; `import:dry-run`). Scope banner verbatim in README. Clone row in `saas-foundation/CLONES.md`. Model pin merged into `.claude/settings.json`. Port 5500 confirmed and its row added to `~/.claude/CLAUDE.md`. `?connection_limit=10&pool_timeout=20` on local `DATABASE_URL`s. `vercel.json` with the house `ignoreCommand`. Reuse check run and recorded in `docs/decisions.md`. Billing and share-link modules removed or unwired per D-5, recorded. *Acceptance:* `npm test`, `npm run foundation:drift` green on the untouched template; every command runs.
- [ ] **1.2 Fixtures committed.** `python3 tools/build_fixtures.py --seed 20261014` into `fixtures/`; `python3 tools/reference_matcher.py --write-decisions` for `decisions_a.csv`, `decisions_b.csv`; `python3 tools/verify_fixtures.py` and `python3 tools/golden_answers.py` print OK; hashes equal brief §12. **Commit the fixtures before any test reads them.** CI fails if product code writes to `fixtures/`. *Acceptance:* `fixtures:check` OK on a clean checkout.
- [ ] **1.3 Port, with lineage.** Read the donors first (`docs/portfolio-overlap.md`): money module from LoanBook (`cents` type, `assertCents`, parse-to-cents), canonical JSON + SHA-256 from Adjuster. Record each port in `docs/decisions.md` with the donor path. *Acceptance:* unit tests for `parseCents` on GN-11..GN-14; canonical serializer sorts keys and rejects floats.
- [ ] **1.4 Normalization N1–N9.** `src/import/normalize/`: names (parse split and full forms, suffix, middle-in-first, nickname sets from `matching/nicknames.json`), email, phone, address (abbreviations, unit split, PO box, `line1Key`), ZIP, dates (ISO, M/D/Y, M/D/YY pivot, Excel serial, month names), amounts to cents, state, encoding detection. *Acceptance:* GN-01..GN-20 pass as vitest cases copied from the brief; each normalized value carries the rule code that fired.
- [ ] **1.5 Parse and map.** CSV reader (BOM, UTF-8 → cp1252 fallback, CRLF/LF, quotes); header synonym mapper from `import/synonyms.json`; proposed map confirmed or overridden by a JSON map file; unmapped columns to `extras`; a map missing `amount`, `gift_date` or both name fields is refused. *Acceptance:* both fixture files map without hand edits; `Table #`, `Notes` and `Source` appear in `extras`; cp1252 detection recorded for file B; a test with a day-first date yields `DATE_INVALID`.
- [ ] **1.6 Validation.** Closed code set from brief §4; `OK` / `WARN:` / `REJECT:` per row with totals by code. *Acceptance:* `expected_validation` matches on all 650 rows (REJECT vs not, and the code when REJECT); rejected rows carry their reason and are excluded from matching.
- [ ] **1.7 Matcher (pure).** `src/matching/`: Jaro-Winkler, Soundex, blocking keys B1–B5, `scorePair` from `matching/model.v1.json`, hard block, conflict caps, floors, flags, decision. No imports from `@/core`, prisma, `Date`, `Math.random`, `fetch`. *Acceptance:* GA-01..GA-20 pass with the exact points, reasons (in order) and flags; a symmetry test swaps arguments on every GA pair; JW(`jon`,`john`) = 0.9333; Soundex(`Flores`) = Soundex(`Florse`) = F462; `model:lint` OK and the model hash recorded in `docs/decisions.md` D-16.
- [ ] **1.8 Batch resolution + `import:eval`.** Resolve rows in file order against the CRM fixture plus accepted rows (D-15: merged rows enrich the target's identifiers and keys; review rows index as themselves; rejects not indexed). `import:eval` prints the brief §11 table for both files and diffs per-pair decisions against `fixtures/decisions_*.csv`. *Acceptance:* every field equals the reference output in `fixtures/samples/reference_matcher.output.txt` for the frozen hashes: A precision 1.000 / recall 0.946 / 58 rows in review / 685 pairs; B 1.000 / 0.955 / 33 / 394; zero pair-decision drift; the row confusion tables match.

- [ ] **1.11 `docs/EVAL.md`.** The §11 table as measured by TypeScript, the fixture hashes, the hand-label results, and the D-30 wording about what the numbers are and are not. *Acceptance:* every number in it is produced by a command named next to it.
- [ ] **1.12 CI gate.** Pipeline fails if `import:eval` drifts, `fixtures:check` fails, `model:lint` fails or a float reaches a cents field (lint). Prove it on a throwaway branch by changing one point in `model.v1.json` (then revert). *Acceptance:* the red run and the green run are both linked in `NEXT.md`.

**Exit criteria:** GN-01..GN-20 and GA-01..GA-20 pass in TypeScript; `import:eval` reproduces the reference table and per-pair decisions exactly on both files; `expected_validation` matches on 650 rows; Shane's 30 labels are recorded with their agreement numbers and O-2/O-3 are decided; `docs/EVAL.md` exists; CI enforces the gate; `src/matching/` has no forbidden import.
